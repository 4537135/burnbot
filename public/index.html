Welcome to Burnbot

Burnbot turns how hard you work with your AI coding agent into a level. The robot shows the level you are on.

  • Nothing to set up. It reads the session logs that Claude Code already keeps on this Mac.
  • Private. No account and no API key. Nothing leaves this Mac.
  • Calibrated to you. Levels are judged against your own last 30 days, so locked in means well above your normal.
